# Components (`fe-mycourse`)

_Last audited: 2026-05-20 (Phase 7 — complete shadcn catalog)._


Inventory of all React components, their responsibilities, and where they live. Keep this updated as new components are added.

---

## Organization Principle

| Directory | Type | Rule |
|-----------|------|------|
| `src/components/ui/` | Design primitives | Generated by shadcn CLI. Do not hand-edit structural logic. Upgrade via `npx shadcn add <component>`. |
| `src/components/common/` | Layout chrome | Components that appear on every page: Header, Footer, Auth chrome. |
| `src/components/home/` | Feature-specific | Components used only on the Home page. |
| `src/components/shared/` | Cross-feature | Components used across multiple features but not in the global layout. |
| `src/components/providers/` | Context providers | Wrap the app in shared context (SWR config, etc.). |
| `src/components/demo/` | Sandbox | Temporary / demo components not wired to any route. |

## Component Conventions

### Client vs Server boundary

| Pattern | Usage |
|---------|-------|
| `"use client"` | Required for hooks (`useState`, `useEffect`, SWR, Zustand), event handlers, Radix interactive primitives |
| No directive (default) | Server Component — preferred for pure rendering, avoids client bundle |

### Naming

- **Component files**: `kebab-case.tsx` (e.g. `auth-layout.tsx`)
- **Component exports**: `PascalCase` (e.g. `export function AuthLayout`)
- **Barrel files**: always `index.ts` — re-export named components

### Styling

- Use `cn()` from `@/lib/utils` to combine Tailwind classes conditionally:
  ```ts
  import { cn } from "@/lib/utils";
  <div className={cn("base-class", condition && "conditional-class")} />
  ```
- Do not use inline `style={{}}` for layout — prefer Tailwind utilities.

### i18n

Components that display user-visible text MUST use `useTranslations`:

```ts
import { useTranslations } from "next-intl";
const t = useTranslations("auth"); // namespace matches src/messages/*.json key
```

Add new strings to both `en.json` and `vi.json` — never hard-code display strings.
