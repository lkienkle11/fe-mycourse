# Shared / Reusable Assets

All reusable utilities, hooks, types, schemas, stores, constants, API callers, Server Actions and components of `fe-mycourse`. **Check this file before creating any new utility, hook, type, schema, constant or component** (duplicates are rejected in review). One row per asset: `Asset | Type | Path | Purpose / reuse`. Rules that belong to a whole feature live in the matching entry of [`FEATURES.md`](FEATURES.md); where a row says "FEATURES `slug`" the full behavior is there. Scope, dependency and usage lists of the old per-asset format were dropped because `grep -rn "<Asset>" src` answers them; every retained row was kept with its purpose and reuse rule.

Sections: UI Primitives, Static Images, TypeScript Types & Interfaces, Error Codes & Constants, Utility Functions, Zod Schemas, Zustand Stores, React Hooks, API Layer Functions, Server Actions, Supporting Type Utilities, Stream events (realtime), SEO / Performance / Security web, Components.
