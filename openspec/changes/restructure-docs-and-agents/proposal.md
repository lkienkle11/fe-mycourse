## Why

`fe-mycourse` has 26 `docs/*.md` files plus 7 `docs/delivery/*.md` stubs (about 10.2k lines, 849 KB) whose redundancy was confirmed by reading the files, not only the filenames:

- Flows are told twice: `flow.md` (522 lines) and `logic-flow.md` (615 lines) both contain "Login Flow" and "Social OAuth Login Flow", and also overlap on token refresh, `/me` loading, the route-based auth modal and stream events.
- Routes, layouts and locale are told in up to four places: route tables live in `router.md`, `screens.md` and `pages.md`; "Locale Configuration" is in both `router.md` and `screens.md`; "Layout Hierarchy" is in `architecture.md`, `router.md`, `screens.md` and `pages.md`; route constants and API route constants are in `architecture.md`, `api-using.md`, `router.md` and `screens.md`; the locale middleware is described in `architecture.md`, `router.md` and `deploy.md` Appendix C.
- The directory map is in `architecture.md` and `folder-structure.md`; UI primitives / shared components are in `components.md`, `screens.md` and `reusable-assets.md`.
- Nearly every file carries a copy-pasted `_Last audited: 2026-10-19 (home SEO: ...)` line 3 (about 800 bytes each) produced by the "sync every doc after every task" rule. It records that a file was touched, not what it says, and is the drift mechanism itself.
- `README.md`'s "Documentation in this repo" index lists 17 of the 26 files; 8 are missing (`api-overview`, `course-collaboration-handoff-2026-06-04`, `instructor-admin`, `instructor-application`, `media-collection`, `modules`, `pages`, `taxonomy-admin`). `architecture.md` still states "1570 symbols / 3189 relationships" while GitNexus reports 6100 / 13186.
- `docs/reusable-assets.md` is 1669 lines / 144 KB at about 8 lines per asset and contains a stale "Gap Analysis" (course/lesson/enrollment types "Phase 02+") and a catch-all "Additional audited reusable assets".

The AI-agent workflow has the same problem. `AGENTS.md` is 56,831 bytes (863 lines); `be-mycourse/AGENTS.md` is 60,339 bytes. Codex loads only 32 KiB (32,768 bytes) of project instructions by default, so the tail (reuse rule, quality gates, documentation sync, secrets policy) can be silently dropped. The Initial Phase also tells the agent to "thoroughly read all project documentation", which is not workable against 849 KB of docs. `be-mycourse` already restructured its docs to four files and consolidated several `AGENTS.md` sections in six local, unpushed commits (`5c23ec6`, `2c4869c`, `e7a6f7b`, `841b7c5`, `1398f36`, `747730a`) but left the size problem and the `fe-mycourse` port open.

Two rules in both repos are factually wrong: the Commit rules say "allow the Husky `pre-commit` hook to run `make check-all`", but neither repository has Husky, a `.husky` folder, a `core.hooksPath`, an installed hook, or (for `fe-mycourse`) a `Makefile`. And "never store secrets" contradicts "persist the complete final answer verbatim in `lastResponse.md`".
