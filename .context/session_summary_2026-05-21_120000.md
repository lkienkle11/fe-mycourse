## Features shipped

### Mobile sidebar (`header-mobile-sidebar.tsx`)

- Portal overlay `z-200`; panel **right** (`right-0`, `translate-x-full` → `translate-x-0`).
- Open/close via single `open` state + Tailwind `transition` (no rAF/timeouts).
- `pointer-events-none` + `inert` when closed; body scroll lock + Escape while open.

### Browse menu tree

- Leaf links: `no-underline!` / `hover:no-underline!` (override `AccordionContent` `[&_a]:underline`).

### Login / signup popup

- Full viewport shell: `inset-0 flex center`, overlay `z-300`, content `z-301`.
- Card `max-w-200` centered; close `DialogClose` on card (`showCloseButton={false}` on `DialogContent`).
- `LoginSignupPopup` mounted **after** `</header>` (outside sticky `z-100`).
- `DialogContent` gains optional `overlayClassName`.

### Language (`useCustomLanguage`)

| Piece | Path |
|-------|------|
| Resolve helpers | `src/lib/language/resolve-language.ts` |
| Zustand store | `src/store/language/language-store.ts` |
| Sync hook | `hooks/language/use-sync-language-from-locale.ts` |
| Read hook | `hooks/language/use-custom-language.ts` |

Returns: `languageCode`, `locale` (alias), `languageLabel`.

- `LanguageLocaleSync` in `AppProviders` (same pattern as `MeSwrSync`).
- `LocaleSwitcher` reads `languageLabel` from hook; removed `switchedLocale` prop chain from `WebLayout` → `Header`.
